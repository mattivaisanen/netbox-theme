# Changelog

## Unreleased

New:

- Theme editor (*Plugins → Theme*): one color scheme for every user, set
  separately for light and dark mode, with presets, a color picker per
  color and a live preview.
- Custom colors: your own named colors, offered in every dashboard widget's
  color choice next to NetBox's.
- Status colors: one badge color per status (Active, Planned...) on every
  object type, from NetBox's colors or your own.
- Rack elevations follow the theme's page colors.
- Colors for the top bar, card headers, table headers and form fields.
- Login page logo, set separately from the sidebar logo.
- Logo upload for the sidebar, per mode, with height and spacing (even
  above and below by default).
- The "Community" edition label under the logo can be hidden or replaced.
- *Restore NetBox defaults*, and *Export* / *Import* of the theme as a JSON
  file.
